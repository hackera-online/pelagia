# Pelagia – базов онлайн магазин (static)

Структура:
- index.html – начална страница (hero, highlights, колекция, split секции, THE EDIT)
- bags.html – категория (ляв сайдбар + грид 5 колони)
- assets/css/style.css – целият дизайн (токени най-горе)
- assets/js/data.js – менюта и продукти (тук се менажира съдържанието)
- assets/js/main.js – header, mega меню, footer, количка, рендер на продукти
- wrangler.toml – деплой в Cloudflare Workers (`npx wrangler deploy`)

Снимки: на местата с клас `.ph` сложи `<img>` или background-image.
Замени "PELAGIA" с името на клиента.
